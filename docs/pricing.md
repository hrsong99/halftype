## Pro, later: only if the fake door shows demand
- **What it is:** Personal Model, a LoRA trained on the user's own text (sent Mail, Messages, a KakaoTalk export, then what they type) and retrained as it grows.
- **Trained on a rented GPU, not the Mac (changed 2026-11-09):** on-device training depends on a laptop we can't see, and when it's idle; a bad experience. The Mac sends the training rows over TLS to a serverless GPU (Modal), which keeps them only in the job's `/tmp`, deletes them before it returns, logs counts only, and sends back the adapter, which stays on the Mac. It works for John's own adapter now: `lab/cloud/` in the private `hrsong99/halftype-train` repo. **Cost per run, measured 2026-11-09:** John's 3,014 messages (493k tokens), Kanana on an L4, trained in 448 s, ~10 min billed with start-up and model load: ~$0.15 at $0.80/h, inside Modal's $30/month free credit. Validation loss 2.63, against the Mac's 2.61. **Before anyone else's text goes up (checked 2026-11-10):** Modal keeps every Function's inputs and outputs for up to 7 days, encrypted at rest ([security](https://modal.com/docs/guide/security)), so `train.py` passing the rows as a call argument left them, and the returned adapter, there for a week. **Fixed 2026-11-10** (halftype-train 783da4b): each run's rows go by HTTPS POST to a Modal Server in that run's own ephemeral app, behind a token made for the run, and the adapter comes back as the response; Servers store no request or response ([retention table](https://modal.com/docs/guide/security)). Still to do: Modal's confirmation of that in writing. Modal's [DPA](https://modal.com/legal/dpa) applies automatically with its terms (processing only to provide the service, staff access need-to-know, SCCs, subprocessors at trust.modal.com); its logs keep 1 day on Starter, and ours hold counts only. Still to write: our own privacy policy (PIPA, GDPR), naming Modal as a processor. The README and site already describe it as opt-in (2026-11-09); the app's own lines ("Nothing you type is sent", Window.swift) change in the release that adds the upload. Confidential GPUs (attested, as Apple's Private Cloud Compute) are the stronger promise, at ~5-9× the price; Colab and Kaggle are not for customer text.
- **Price (a guess, not tested):** $4/month, $36–40/year, $99 lifetime. Lifetime is set at ~2.5× the yearly price, as Superwhisper does (~2.9×). At 2× (for example $80), most buyers would take lifetime and the recurring revenue would never come.

## Saved typing: to do before any typed text is written to disk
Simple, and robust against the realistic threats (another user or app on the Mac, a backup, a stolen disk image), not a nation state:
- Opt-in, off by default, under General > Personal Model; secure fields and paused apps are never saved, as today.
- One file in Application Support, encrypted (AES-GCM, CryptoKit) with a key in the user's Keychain, so a copied file or a Time Machine backup is unreadable without their login; excluded from backups anyway.
- Delete All, one button, removes the file and the key; turning the option off asks to delete. Also a cap (e.g. the newest few months), oldest dropped first.
- The user can see what's kept (count, date range, and the text itself on request).
- Never in logs, crash reports or Stats; uploaded only for a training run the user starts, as today (`lab/cloud/`).
- Codex reviews it as security-sensitive before it merges.
