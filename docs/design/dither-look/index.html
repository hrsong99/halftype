Itda's window in the "dithered" look

Deciding: should Itda's one window (Try It, and the pages behind the sidebar) take the look of Jon Kelley's Devin redesign: dark, a dithered pixel backdrop, frosted glass on top. John: "I kinda like how this looks, can you show me some variants of our app looking like that."

Recommendation: D, or B if you want the full Devin feel. The window is the first thing a new user sees and almost nothing after, so a striking backdrop costs little and sells "local, crafted". But Itda's real product is grey ghost text in other apps; a busy full-bleed backdrop (B, C) fights the one thing the window demonstrates, grey text on a field. D keeps the dither as a glow behind the field and plain everywhere else, so the Models / Apps / General pages stay readable. Build cost is small for all of them: the target is macOS 26, so the glass is SwiftUI's own .glassEffect, and the dither is either one bundled PNG per appearance (simplest) or a ~30-line Metal .colorEffect shader if it should move (F). Mac-only app, so the Android/iOS question doesn't apply.
