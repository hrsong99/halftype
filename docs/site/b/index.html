Korean, finished mid-syllable.

The syllable you are composing stays out of the prompt, and suggestions must fit what your 2-set keys can still make. Tab presses the remaining keys, so the input method finishes the syllable.

On 1,099 mid-syllable requests from public Korean text, keystrokes saved per request rose from 0 to 0.69. Wrong suggestions rose too: 18.2%, against 8.4%.

Your typing stays local.

The model runs on your Mac. Halftype goes online only to fetch models from Hugging Face and, about once a day, to check GitHub for an update, which you can turn off. Typed text is never saved or logged. It asks for one permission, Accessibility, and skips password fields.

Questions before you download.

What do I need?

macOS 26 or later. It is tested only on Apple Silicon, on one M5.

Which Korean layout?

Apple's 2-Set Korean. With another layout, Halftype shows nothing after a Hangul character.

How good is Korean?

Weaker than English. About a fifth of the default model's Korean suggestions match exactly, a third with Kanana 1.5.

Where does it stay silent?

With text after the caret on the same line, during Secure Input, and in password fields.

How finished is it?

An early release, used so far by its author. Open an issue with what you find.
